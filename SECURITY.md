# Security and responsible use

[English](SECURITY.md) · [Español](SECURITY.es.md)

---

This repository is independent defensive research. It contains no exploit code and no
infrastructure data.

- Do not use the described techniques against systems you do not own or have explicit written
  authorization to test.
- For vulnerabilities in PHP, follow the PHP project's security process:
  https://www.php.net/security/
- For vulnerabilities in a third-party application, contact that vendor's security team.
- Do not open public issues containing unpatched exploitation details for systems that are still
  exposed.

The measurements in `EVIDENCE.md` were obtained in disposable lab containers on loopback
interfaces. Public PoCs are referenced by URL; their code is not redistributed here. The lab
proof-of-concept code lives in a separate private, invite-only repository, available on request
from the author to vetted reviewers.
