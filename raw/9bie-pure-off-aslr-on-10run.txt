=== boundaries of this row ===
- Requires the stock 128M geometry + the official php.ini-production. At memory_limit=8M the
  same chain is 0/3 with one worker, while 128M with one worker gives 3/3: the offsets and the
  leak window are calibrated for the 128M geometry. A1 itself does trigger at 8M — our older
  chain goes 8/8 there with display_errors=On (see PORTABILITY.md) — so what fails is the
  calibration, not the trigger.
- The repo's own tooling/docker-compose.yml does not reproduce it: vuln-8426 loads no php.ini
  (Loaded Configuration File => (none)) and reports display_errors => STDOUT. Adding only
  display_errors=Off on top of hardening-off.ini gives 0/3, because B1 finds no pointers: the
  chain is calibrated for php.ini-production, not for a conf.d overlay.
- Cold start not characterized: a first run on a freshly created target gave 0/3 with
  'no heap pointers in leak window'; after docker restart the same target gave 3/3. The 10/10
  above restarts before each run.
- 149 holders pinned; if MaxRequestWorkers differs, --workers N has to be adjusted, and if more
  than N-1 are busy the requests queue and B1 may land on another child.
- FPM and CVE-2026-115560 were not measured: the stock path already closed the question.
